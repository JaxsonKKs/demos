# Mainfront: sample websites

Websites for local businesses in Stony Plain, Alberta, built by Jaxson.

**Portfolio:** https://jaxsonkks.github.io/demos/mainfront/

Every site is built around one real object from its trade (a barber's shop window, a plumber's pressure gauge, a florist's gift tag), with its own colours and fonts, one useful live feature, and a tap-to-call bar on phones.
